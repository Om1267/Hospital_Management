# Contributing to Hospital Management System

Thank you for your interest in contributing!

## Getting Started

1. Fork the repository
2. Clone your fork: git clone https://github.com/your-username/Hospital_Management.git
3. Create a virtual environment: python -m venv venv
4. Activate it: env\Scripts\activate (Windows) or source venv/bin/activate (Linux/Mac)
5. Install dependencies: pip install -r requirements.txt
6. Run the app: python app.py

## Development Guidelines

- Follow PEP 8 for Python code style
- Add comments for complex logic
- Write descriptive commit messages
- Test your changes before submitting a PR

## Submitting a Pull Request

1. Create a feature branch: git checkout -b feature/your-feature-name
2. Make your changes and commit them
3. Push to your fork
4. Open a Pull Request with a clear description

## Reporting Issues

Please use GitHub Issues to report bugs or request features.
